# AGENTS.md

Neovim configuration based on kickstart-modular.nvim. Uses `NVIM_APPNAME="dvim"` to run as a separate Neovim instance.

## Structure

- `init.lua` -- entry point: sets leader (Space), loads modules in order
- `lua/options.lua` -- vim options
- `lua/keymaps.lua` -- keymaps and autocommands (basic, from kickstart)
- `lua/lazy-bootstrap.lua` -- bootstraps lazy.nvim plugin manager
- `lua/lazy-plugins.lua` -- plugin spec (loads kickstart plugins + imports `custom.plugins`)
- `lua/kickstart/plugins/` -- base plugin configs from kickstart (lspconfig, conform, blink-cmp, etc.)
- `lua/custom/plugins/` -- **user customizations** (auto-imported via `{ import = 'custom.plugins' }`)

## Commands

| Task | Command |
|------|---------|
| Format Lua | `stylua .` |
| Check formatting | `stylua --check .` |
| Manage plugins (inside Neovim) | `:Lazy` |
| Update plugins | `:Lazy update` |
| Check health | `:checkhealth` |
| Run as separate instance | `NVIM_APPNAME="dvim" nvim` |

No Makefile, test suite, or build system exists. There is nothing to "build" -- just Lua files loaded by Neovim.

## Conventions

- **Indentation**: 2 spaces, Unix line endings (enforced by `.stylua.toml`)
- **Quotes**: single-preferred (`AutoPreferSingle`)
- **Call parentheses**: omitted (`call_parentheses = "None"`) -- write `require 'foo'` not `require('foo')` for simple calls
- **Column width**: 160
- **Collapse**: simple statements collapsed to one line (`collapse_simple_statement = "Always"`)
- **Leader key**: Space (set before plugins load)
- **Nerd Font**: enabled (`vim.g.have_nerd_font = true`)

## Keymap philosophy

| Prefix | Purpose |
|--------|---------|
| `<leader><leader>` | Global grep (live) |
| `<leader>/` | Find files by name |
| `<leader>f` | Find/file (unified search group) |
| `<leader>c` | Code actions (format, rename, symbols) |
| `<leader>g` | Git (lazygit, hunks, branches, log) |
| `<leader>t` | Tools (`tr` = REST subgroup) |
| `<leader>s` | Settings (`su` = ui, `st` = toggles) |
| `<leader>b` | Buffer operations |
| `<leader>w` | Windows (proxy to `<c-w>`) |
| `<leader>e` | Explorer |
| `<leader>x` | Diagnostics/quickfix |
| `<leader>q` | Quit |
| `g` | Goto (LSP: `gd`, `gr`, `gI`, `gy`) |

## Adding plugins

Each custom plugin gets its own file in `lua/custom/plugins/` returning a lazy.nvim plugin spec table. Files are auto-loaded via the import in `lazy-plugins.lua`. Base kickstart plugins live in `lua/kickstart/plugins/` -- override them from custom by using the same plugin name with new opts.

## Architecture notes

- **Telescope is disabled** (`enabled = false`) -- fzf-lua is the fuzzy finder
- **Snacks picker is disabled** -- Snacks is only used for explorer, dashboard, lazygit, bufdelete, indent, notifier, etc.
- **mini.statusline is disabled** -- lualine replaces it
- **Format on save is disabled by default** -- manual format via `<leader>cf`, toggle with `<leader>stf` (global) / `<leader>stF` (buffer)
- **Python LSP**: ty (type checker, linting only with many beta rules ignored) + ruff (linting/formatting, hover/completion disabled)
- **Mason auto-installs**: ty, ruff, vtsls, djlint, django-template-lsp, prettierd, prettier

## Gotchas

- `lazy-lock.json` is **not** gitignored (the ignore line is commented out) -- it should be committed if present.
- CI (`stylua.yml`) only triggers on the upstream `nvim-lua/kickstart.nvim` repo, not this fork.
- `.luarc.json` is gitignored (generated by lua-language-server).
- The `codestats.lua` file contains an API key -- do not share publicly.
- Django filetype detection depends on files being under a `templates/` directory path.
